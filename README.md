# ALMA

App móvil exclusiva para parejas — comunicación, organización y conexión emocional.

## Documentación

- [ARQUITECTURA.md](ARQUITECTURA.md) — Stack, módulos, esquema de BD, WebSockets, infraestructura y plan de fases.

## Stack

- **Frontend:** Flutter 3 + Riverpod 2
- **Backend:** NestJS + PostgreSQL + Redis + BullMQ
- **Infra:** Vultr VPS + Docker Compose + Nginx + FCM
